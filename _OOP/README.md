**Encapsulation:**
- *Definition:* Bundles data (attributes) and methods (functions) into a class for modularity & information hiding.
- *Purpose:* 
  - Hides the internal state of an object, 
  - Restricts access to implementation details, 
  - Promotes modularity and information hiding.

**Inheritance:**
- *Definition:* 
  - Allows a new class (subclass or derived class) to inherit characteristics & behaviors from an existing class (superclass or base class). 
  - The new class can extend or override the functionality of the existing class.
- *Purpose:* 
  - Promotes code reusability, 
  - Creates a hierarchical structure where common attributes & behaviors are shared among related classes.

**Polymorphism:**
- *Definition:* Enables objects of different classes to be treated as objects of a common base class. It enables a single interface to represent different types or forms.
- *Purpose:* 
  - Simplifies code, 
  - Promotes flexibility, 
  - Allows the creation of generic code that can work with objects of various types without knowing their specific classes.

**Abstraction:**
- *Definition:* Simplifies complex systems by modeling classes based on their essential characteristics & ignoring irrelevant details.
- *Purpose:* 
  - Manages complexity by focusing on high-level concepts, 
  - Reduces the impact of changes, 
  - Allows working with abstract representations of objects rather than every detail.
